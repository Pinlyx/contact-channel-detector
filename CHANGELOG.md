# Changelog

## 0.1.0 - 2026-11-20

- First release: library (`detect`, `detect_html`) and CLI (`contact-channels`).
- Detects WhatsApp, Telegram, Messenger, Viber, 25+ live chat widgets and WordPress WhatsApp plugins, social profiles (Instagram, Facebook, X, TikTok, YouTube, LinkedIn, Pinterest, Threads, Bluesky), e-mail (including Cloudflare-obfuscated) and phone.
- Parked, default-server and placeholder page flag.
- JSONL and CSV output, percentage summary table, robots.txt option.
